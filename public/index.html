Minigram
Telegram 私聊中转机器人

把私聊搬进群组，
带人机验证与话题镜像。

Minigram 部署在 Cloudflare Pages 上：用户私聊 Bot 的消息会被镜像到群组话题，附带 Turnstile 人机验证、消息编辑同步和管理面板。

查看源码 部署文档
功能特性

私聊镜像到话题

用户私聊消息自动转发到群组对应话题，群组回复同步回私聊。

Turnstile 人机验证

首次使用需通过 Cloudflare Turnstile，验证有效期 7 天。

消息编辑同步

双向编辑自动同步：私聊改动会更新群组副本，反之亦然。

管理面板

话题内发送 /admin 打开面板：拉黑、解黑、查用户、开关验证、删用户。

删除同步

回复消息发送 /del，同时删除群组副本与私聊副本。

Cloudflare 原生

Pages Functions + D1 数据库，无需服务器，全部跑在 Cloudflare 边缘。

用户使用流程
1
私聊 Bot 向机器人发送任意消息。
2
点击验证按钮 收到「✅ 点击验证」按钮，点击打开 Mini App。
3
完成人机验证 通过 Cloudflare Turnstile 验证，有效期 7 天。
4
开始对话 话题自动创建，消息实时镜像到群组。
管理员操作
在用户话题内发送 /admin 打开管理面板。
直接回复话题内任意消息即可转发回用户私聊。
回复某条消息发 /del 可删除群组副本。
部署提示
本项目需要绑定 自定义域名（不能用 pages.dev）和 D1 数据库，并在 Cloudflare Turnstile 中为同一域名创建站点。
详细的变量清单与部署步骤见仓库 README。
